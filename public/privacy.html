Política de Privacidade

Última atualização: maio de 2025

Resumo objetivo: Coletamos apenas o necessário para entregar o produto. Os prints enviados são usados apenas para gerar a análise e não ficam armazenados permanentemente. Seu e-mail é usado só para enviar o acesso. Não vendemos dados.

1. Quem somos

O ScanCrush é uma plataforma digital de análise contextual de conversas. Esta Política de Privacidade descreve como tratamos os dados pessoais dos usuários, em conformidade com a Lei Geral de Proteção de Dados Pessoais — LGPD (Lei nº 13.709/2018).

Para questões relacionadas à privacidade, entre em contato: privacidade@scancrush.com

2. Quais dados coletamos e por quê

Coletamos dados em dois momentos distintos:

a) Dados recebidos via Kiwify (pagamento)

Quando você realiza uma compra, a Kiwify (nossa plataforma de pagamentos) nos envia automaticamente:

DadoFinalidade
Nome e e-mail do compradorEnviar o link de acesso e personalizar a comunicação
Dados de identificação (CPF, data de nascimento, telefone quando fornecidos)Registro da compra e verificação de elegibilidade
ID e status do pedidoConfirmar pagamento aprovado e prevenir duplicidade
Produto e plano adquiridoDefinir as condições do acesso contratado
Dados de pagamento (método, valor)Registro contábil e fiscal obrigatório

b) Dados gerados durante o uso

DadoFinalidade
Credencial de acesso ao serviçoControlar que cada compra gera um acesso único
Prints / imagens enviadosProcessamento temporário para gerar a análise
Data e hora de utilização do acessoRegistro operacional e suporte
Registros de aceite (termos, privacidade, 18+)Comprovação do consentimento

Não coletamos: RG, dados de cartão de crédito (processados diretamente pela Kiwify), localização geográfica ou dados de navegação para fins de rastreamento.

3. Sobre os prints enviados

Os prints (imagens de conversas) que você envia representam o dado mais sensível tratado pela plataforma. Nossa política é:

  • Uso exclusivo para processamento: os prints são enviados à IA para gerar a análise e não servem para nenhuma outra finalidade
  • Sem armazenamento permanente: após o processamento da análise, os prints são descartados e não ficam salvos em nossos servidores
  • Sem histórico: não criamos banco de imagens, não vinculamos os prints ao seu perfil e não existe área de membros com histórico de análises
  • Sem uso para treino de IA: não utilizamos seu conteúdo para treinar modelos de inteligência artificial
  • Tratamento temporário: pode haver um período mínimo de retenção temporária durante o processamento técnico, o qual é pelo menor tempo possível e necessário para conclusão da análise
Atenção: Mesmo sem armazenamento permanente de prints, há tratamento temporário desses dados durante a análise. Recomendamos não enviar conteúdo que identifique terceiros que não consentiram com o envio.

4. Base legal para o tratamento (LGPD)

Tratamos seus dados com base nas seguintes bases legais previstas na LGPD (Art. 7º):

DadoBase legal (LGPD)
E-mail, nome, dados da compraExecução de contrato (art. 7º, V) — necessário para entregar o produto comprado
Prints enviados para análiseExecução de contrato (art. 7º, V) — necessário para gerar a análise contratada
Registros de aceite e consentimentoLegítimo interesse do controlador (art. 7º, IX) e cumprimento de obrigação legal
Credencial de acesso e registros operacionaisLegítimo interesse (art. 7º, IX) — segurança e integridade do serviço

5. Compartilhamento com terceiros

Compartilhamos seus dados apenas com os parceiros estritamente necessários para a operação do produto:

  • Kiwify: plataforma de pagamentos e gestão de vendas. Recebemos os dados da compra via webhook. A Kiwify possui sua própria política de privacidade.
  • Provedor de API de IA: os prints e texto são enviados para processamento pela API de inteligência artificial utilizada para gerar a análise. Esse processamento é temporário e regido pelos termos do provedor.
  • Serviço de envio de e-mail: utilizado para enviar o link de acesso ao comprador.
  • Infraestrutura de hospedagem: o sistema opera em servidores seguros com criptografia em trânsito e em repouso.

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais, de marketing ou de qualquer outra natureza não prevista nesta política.

6. Retenção de dados

DadoPeríodo de retenção
Prints enviados para análiseDescartados após conclusão do processamento
E-mail, nome, dados da compraPelo período necessário para suporte e obrigações legais (mínimo 5 anos para fins fiscais, conforme lei)
Credencial de acesso e registro de utilizaçãoPelo período necessário para validação de acesso e suporte
Registros de aceitePelo período necessário para comprovação de consentimento

Após os períodos acima, os dados são eliminados ou anonimizados.

ConfirmaçãoConfirmar se tratamos seus dados

AnonimizaçãoSolicitar anonimização de dados desnecessários
PortabilidadeReceber seus dados em formato estruturado

Para exercer qualquer desses direitos, envie solicitação para: privacidade@scancrush.com

Responderemos em até 15 dias úteis, conforme prazo legal.

8. Segurança dos dados

Adotamos as seguintes medidas de segurança:

  • Transmissão de dados via conexão criptografada (HTTPS/TLS)
  • Credenciais de acesso geradas com segurança criptográfica
  • Acesso aos dados restrito ao pessoal necessário para operação
  • Sem armazenamento permanente de conteúdo sensível (prints)
  • Monitoramento de acessos e operações do sistema

Embora adotemos práticas de segurança adequadas, nenhum sistema é 100% invulnerável. Em caso de incidente de segurança que afete seus dados, notificaremos os titulares e a ANPD conforme exigido pela LGPD.

9. Cookies e rastreamento

O ScanCrush utiliza localStorage do navegador apenas para salvar a preferência de idioma do usuário. Não utilizamos cookies de rastreamento, pixels de publicidade ou ferramentas de analytics de terceiros que identifiquem você individualmente.

10. Transferência internacional

Para processar a análise, seus dados (incluindo prints temporariamente) podem ser enviados a servidores de provedores de IA localizados fora do Brasil. Quando isso ocorre, exigimos que esses provedores ofereçam garantias de proteção equivalentes às exigidas pela LGPD.

11. Dados de menores

O ScanCrush é destinado exclusivamente a maiores de 18 anos. Não coletamos conscientemente dados de menores de idade. Se tomarmos conhecimento de que dados de um menor foram coletados, os eliminaremos imediatamente. Caso você suspeite disso, entre em contato: privacidade@scancrush.com.

12. Alterações nesta política

Esta política pode ser atualizada periodicamente. Publicaremos a nova versão nesta página com a data de atualização. Mudanças significativas serão comunicadas por e-mail quando possível.

13. Contato e encarregado de dados

Para questões sobre privacidade, exercício de direitos ou dúvidas sobre esta política:

  • E-mail: privacidade@scancrush.com
  • Prazo de resposta: até 15 dias úteis
